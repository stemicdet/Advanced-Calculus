    Section Week 14: The Generalized Riemann Integral (8.1)

    Subsection The Generalized Riemann Integral

    We saw in the last section that not every derivative has an integral. Ideally we want to be able to integrate every derivative so that we can state the FTC with no assumptions on integrability.
    🔗
    The Lebesgue integral was introduced in 1904 to integrate functions that can’t be integrated using Riemann integration, but it isn’t perfect. There are functions that can’t be integrated using the Lebesgue integral.
    🔗
    In particular one cannot have the FTC with the Lebesgue integral without some additional restriction of the functions.
    🔗
    In 1960 Jaroslav Kurzweil and Ralph Henstock independently developed a new defintion of the integral called the generalized Riemann integral or the Kurzweil-Henstock integral.
    🔗
    The generalized Riemann integral can integrate even more functions than the Lebesgue integral. In addition using the generalized Riemann integral the FTC can be proven without any additional restrictions on the functions.
    🔗
    Remarkably the generalized Riemann integral is defined by making a slight modification to Riemann’s definition of the integral.
    🔗
    🔗

    Subsection The Riemann Integral

    Definition 83.

    Let \(P= \{x_0,x_1,x_2, \ldots, x_n\}\) be a partition of \([a,b]\text{.}\) A tagged partition is one where in addition to \(P\) we have chosen a point \(c_k\) from each subinterval \([x_{k-1}, x_k]\)
    🔗
    🔗
    Example: Let \(P = \{0,3,5,9,10\}\) be a partition of \([0,10]\text{.}\) An example of a tagged partition is \((P, \{c_k\}_{k=1}^4)\) where \(c_1 = 3\text{,}\) \(c_2 = 5\text{,}\) \(c_3 = 9\text{,}\) and \(c_4= 10\text{.}\)
    🔗
    Another example of a tagged partition is \((P, \{c_k\}_{k=1}^4)\) where \(c_1 = 2\text{,}\) \(c_2 = 5\text{,}\) \(c_3 = 5\text{,}\) and \(c_4= 9.9\text{.}\)
    🔗

    Definition 84.

    Given a function \(f\) and a tagged partition \((P, \{c_k\}_{k=1}^n)\) the Riemann sum generated by this partition is given by
    \begin{equation*} R(f,P) = \sum_{k=1}^n f(c_k) (x_k-x_{k-1}). \end{equation*}
    🔗
    🔗
    The idea of the Riemann sum is that we approximate the area under the curve by rectangles with width \((x_k-x_{k-1})\) and height \(f(c_k)\text{.}\)
    🔗

    Definition 85.

    A partition is said to be \(\delta\)-fine if every subinterval\([x_{k-1},x_k]\) satisfies \(x_k-x_{k-1} < \delta\text{.}\) In other words, every subinterval has width less than \(\delta\text{.}\)
    🔗
    🔗

    Definition 86.

    A function is Riemann integrable if every Riemann sum converges to the same value as the widths of the subintervals tend to \(0\text{.}\)
    🔗
    🔗

    Definition 87. Limit Criterion for Riemann Integrability.

    A bounded function \(f:[a,b] \to \mathbf{R}\) is Riemann integrable with integral
    \begin{equation*} \int_a^b f(x)dx = A \end{equation*}
    if for every \(\epsilon > 0\) there exists \(\delta >0\) such that, for every \(\delta\)-fine tagged partition \((P, \{c_k\}_{k=1}^n)\) it follows that
    \begin{equation*} |R(f,P)-A| < \epsilon. \end{equation*}
    🔗
    🔗
    🔗

    Subsection Gauges and \(\delta\)-fine Partitions

    In the Riemann integral \(\delta\) only depends on \(\epsilon\) and is constant throughout the partition.
    🔗
    We will modify the Riemann integral by letting \(\delta(x)\) be a function of \(x\text{.}\) Thus \(\delta(x)\) depends on both \(x\) and \(\epsilon\text{.}\)
    🔗

    Definition 88.

    A function \(\delta:[a,b] \to \mathbf{R}\) is called a gauge on \([a,b]\) if \(\delta(x) > 0\) on \([a,b]\text{.}\)
    🔗
    🔗

    Definition 89.

    Given a particular gauge \(\delta(x)\) a tagged partition \((P, \{c_k\}_{k=1}^n)\) is \(\delta(x)\)-fine if every subinterval \([x_k, x_{k-1}]\) satisfies \(x_k - x_{k-1} < \delta(c_k)\text{.}\) In other words, each subinterval \([x_k, x_{k-1}]\) has width less than \(\delta(c_k)\text{.}\)
    🔗
    🔗
    If \(\delta(x)\) is a constant function, then this is the same definition as a \(\delta\)-fine partition.
    🔗
    Example: Consider the interval \([0,10]\) and let \(\delta(x) = \frac{x+2}{2}\text{.}\) Let \(P = \{0, 1 ,3,6,10\}\) with tags \(c_1 = 1\text{,}\) \(c_2 = 3\text{,}\) \(c_3 = 5\text{,}\) and \(c_4 = 8\text{.}\) Is \((P, \{c_k\}_{k=1}^4)\) a \(\delta(x)\)-fine partition?
    🔗
    Example: Consider the interval \([0,10]\) and let \(\delta(x) = \frac{x+2}{2}\text{.}\) Let \(P = \{0, 1 ,3,6,10\}\) with tags \(c_1 = 1\text{,}\) \(c_2 = 2\text{,}\) \(c_3 = 6\text{,}\) and \(c_4 = 10\text{.}\) Is \((P, \{c_k\}_{k=1}^4)\) a \(\delta(x)\)-fine partition?
    🔗
    Given a gauge \(\delta(x)\text{,}\) it is not immediately clear that it is possible to find a \(\delta(x)\) fine partition. The next theorem shows that in fact this is always possible.
    🔗

    Theorem 90.

    Given a gauge \(\delta(x)\) on an interval \([a,b]\text{,}\) there exists a tagged partition \((P, \{c_k\}_{k=1}^n)\) that is \(\delta(x)\)-fine.
    🔗
    🔗

    Proof.

    We will do a proof by contradiction. Assume that \(I_0 = [a,b]\) does not have a \(\delta(x)\)-fine partition.
    🔗
    Let \(c = \frac{1}{2}(a+b)\text{.}\) If \([a,c]\) and \([c,b]\) both have \(\delta(x)\)-fine partitions \((P_1, \{c_k\})\) and \((P_2, \{d_k\})\) then the partition \(P= P_1 \cup P_2\) is a \(\delta(x)\)-fine partition of \([a,b]\text{.}\)
    🔗
    Thus at least one of \([a,c]\) and \([c,b]\) must not have a \(\delta(x)\)-fine partition.
    🔗
    Let \(I_1\) denote a subinterval that does not have a \(\delta(x)\)-fine partition.
    🔗
    If we subdivide \(I_1\) into two equal parts similar reasoning shows that at least one part much not have a \(\delta(x)\)-fine partition. Let \(I_2\) denote this subinterval.
    🔗
    Continuing in this way we can construct a nested sequence \(\{I_n\}\) of subintervals so that the length of \(I_n\) is \((b-a)/2^n\) and so that no \(I_n\) has a \(\delta(x)\)-fine partition. Suppose \(I_n = [a_n, b_n]\text{.}\)
    🔗
    By the nested interval property there exists \(c \in \bigcap_{n=0}^{\infty} I_n\text{.}\) Hence \(c \in I_n\) for all \(n\text{.}\)
    🔗
    If \(\frac{b-a}{2^n}< \delta(c)\) then \(I_n\) would have a \(\delta(x)\)-fine partition given by \(P = \{a_n, b_n\}\) with tag \(c\text{.}\) Hence \(\delta(c) \leq \frac{b-a}{2^n}\) for all \(n\text{.}\)
    🔗
    Letting \(n \to \infty\) implies that \(\delta(c) = 0\text{,}\) which contradicts the fact that \(\delta(x)\) is a gauge. Hence \(I_0\) has a \(\delta(x)\)-fine partition.
    🔗
    🔗
    In the previous proof we showed the existence of a \(\delta(x)\)-fine partition by showing that it is impossible for it to not exist, but we didn’t actually find a \(\delta(x)\)-fine partition.
    🔗
    The mathematical philosophy of constructivism asserts that one must actually find the desired object in order to prove that it exists, a proof by contradiction is not good enough. However, only a minority of mathematicians hold this view.
    🔗
    Taking the principle of excluded middle from the mathematician would be the same, say, as proscribing the telescope to the astronomer or to the boxer the use of his fists -- David Hilbert
    🔗
    🔗

    Subsection Generalized Riemann Integrability

    We define the Generalized Riemann Integral by replacing \(\delta\) with \(\delta(x)\) in the definition of Riemann Integral
    🔗

    Definition 91. Generalized Riemann Integral.

    A function \(f\) on \([a,b]\) has generalized Riemann integral \(A\) if, for every \(\epsilon>0\text{,}\) there exists a gauge \(\delta(x)\) on \([a,b]\) such that for every tagged partition \((P, \{c_k\}_{k=1}^n)\) that is \(\delta(x)\)-fine, it is true that
    \begin{equation*} |R(f,P)-A| < \epsilon. \end{equation*}
    In this case we write \(A = \int_a^b f(x) dx\)
    🔗
    🔗

    Theorem 92.

    If \(f\) is Riemann integrable, then \(f\) is generalized Riemann integrable.
    🔗
    🔗

    Proof.

    Let \(\delta(x) = \delta\text{.}\)
    🔗
    🔗
    Recall that the Dirichlet function
    \begin{equation*} g(x) = \begin{cases} \hfill 1 \amp \text{ if $x \in \mathbf{Q}$} \\ \hfill 0 \hfill \amp \text{ if $x \notin \mathbf{Q}$} \end{cases} \end{equation*}
    is not Riemann integrable.
    🔗

    Theorem 93.

    Dirichlet’s function \(g(x)\) is generalized Riemann integrable on \([0,1]\) with \(\displaystyle \int_0^1 g(x) dx = 0\text{.}\)
    🔗
    🔗

    Proof.

    Let \(\epsilon > 0\text{.}\) We must construct a gauge \(\delta(x)\) so that whenever \((P, \{c_k\}_{k=1}^n)\) is a \(\delta(x)\)-fine partition it follows that
    \begin{equation*} \sum_{k=1}^n g(c_k) (x_k-x_{k-1}) - 0 < \epsilon \end{equation*}
    🔗
    Since \(g(x) = 0\) when \(x\) is irrational, we only need to worry about keeping the rational numbers in sufficiently small subintervals.
    🔗
    Let \(\{r_1, r_2, r_3 \ldots\}\) be a countable listing of the rational numbers. For each \(r_k\) set \(\delta(r_k) = \frac{\epsilon}{2^{k}}\text{.}\) For \(x\) irrational, set \(\delta(x) = 1\text{.}\)
    🔗
    Now we will show that if \((P, \{c_k\}_{k=1}^n)\) is a \(\delta(x)\)-fine partition then
    \begin{equation*} \sum_{k=1}^n g(c_k) (x_k-x_{k-1}) < \epsilon \end{equation*}
    🔗
    Because \(g(c_k) = 0\) when \(c_k\) is irrational, we only need to worry about those \(c_k\) that are rational.
    🔗
    The worst case scenario is that every \(c_k\) is rational.
    🔗
    Because \((P, \{c_k\}_{k=1}^n)\) is \(\delta(x)\)-fine, this means that \((x_k - x_{k-1}) < \delta(c_k) = \frac{\epsilon}{2^{k+1}}\text{.}\)
    🔗
    Hence
    \begin{align*} \sum_{k=1}^n g(c_k) (x_k-x_{k-1}) \amp < \sum_{k=1}^n 1 \cdot \frac{\epsilon}{2^{k}} \\ \amp = \epsilon\sum_{k=1}^n \frac{1}{2^{k}} \\ \amp \leq \epsilon \cdot 1 = \epsilon \end{align*}
    🔗
    Thus \(g(x)\) is generalized Riemann integrable and \(\displaystyle \int_0^1 g(x) dx = 0\text{.}\)
    🔗
    🔗
    \(g(x)\) is not Riemann integrable, because given a Partition \(P\) with \(\Delta_x < \delta\text{,}\) one can choose all the tags to be rational numbers so that \(R(f,P) = 1\text{,}\) and one can choose all the tags to be irrational numbers so that \(R(f,P) = 0\text{.}\)
    🔗
    Choosing all the tags to be rational numbers does not lead to a \(\delta(x)\)-fine partition, so it does not need to be considered when determining the generalized Riemann integrable.
    🔗
    🔗

    Subsection The Fundamental Theorem of Calculus Revisited

    When we proved the FTC for Darboux integrals we needed to assume that the function \(f(x)\) was an integrable function, but for the generalized Riemann integral we no longer need that assumption.
    🔗

    Theorem 94. Fundamental Theorem of Calculus.

    Suppose that \(F:[a,b] \to \mathbf{R}\) is differentiable at every point \(x \in [a,b]\text{.}\) and set \(f(x) = F'(x)\text{.}\) Then \(f\) has the generalized Riemann integral
    \begin{equation*} \int_a^b f(x) dx = F(b) - F(a) \end{equation*}
    🔗
    🔗

    Proof.

    Let \(P = \{x_0, x_1, \ldots, x_n\}\) be a partition of \([a,b]\) and note that
    \begin{equation*} F(b) - F(a) = \sum_{k=1}^n [F(x_k) - F(x_{k-1})] \end{equation*}
    🔗
    Let \(\{c_k\}_{k=1}^n\) be a set of tags for \(P\) and let \(R(f,P)\) be the Riemann sum over this tagged partition.
    🔗
    We can estimate the difference between \(R(f,P)\) and \(F(b)-F(a)\) by
    \begin{align*} |F(b)-F(a) - R(f,P)| \amp = \left| \sum_{k=1}^n [F(x_k) - F(x_{k-1}) - f(c_k) (x_k-x_{k-1})] \right|\\ \amp \leq \sum_{k=1}^n |F(x_k) - F(x_{k-1}) - f(c_k) (x_k-x_{k-1})| \end{align*}
    🔗
    Let \(\epsilon > 0\text{.}\) To prove the theorem we need to find a gauge \(\delta(c)\) so that \(|F(b)-F(a) - R(f,P)| < \epsilon\) whenever \(P\) is a \(\delta(c)\)-fine partition.
    🔗
    Because \(F\) is differentiable with derivative \(f\text{,}\) for each \(c \in [a,b]\) there exists \(\delta(c) > 0\) such that
    \begin{equation*} \left| \frac{F(x)-F(c)}{x-c} -f(c) \right| < \epsilon \end{equation*}
    whenever \(0 < |x-c| < \delta(c)\text{.}\)
    🔗
    This function \(\delta(c)\) is the gauge we want on \([a,b]\text{.}\)
    🔗
    Now let \((P, \{c_k\}_{k=1}^n)\) be a \(\delta(c)\)-fine partition of \([a,b]\text{.}\) We will show that \(|F(b)-F(a)-R(f,P)| < \epsilon\text{.}\)
    🔗
    For a particular \(c_k \in [x_{k-1},x_k]\text{,}\) \(|x_k - c_k| < \delta(c_k)\text{.}\) Hence
    \begin{equation*} \left| \frac{F(x_k)-F(c_k)}{x_k-c_k} -f(c_k) \right| < \epsilon. \end{equation*}
    🔗
    Multiplying both sides by \(x_k-c_k\) yields
    \begin{equation*} \left| F(x_k)-F(c_k) -f(c_k) (x_k-c_k)\right| < \epsilon (x_k-c_k). \end{equation*}
    🔗
    Similarly, since \(|c_k-x_{k-1}| < \delta(c_k)\)
    \begin{equation*} \left| \frac{F(c_k)-F(x_{k-1})}{c_k-x_{k-1}} -f(c_k) \right| < \epsilon. \end{equation*}
    🔗
    This time multiplying both sides by \(c_k - x_{k-1}\) gives
    \begin{equation*} \left| F(c_k)-F(x_{k-1}) -f(c_k) (c_k-x_{k-1}) \right| < \epsilon (c_k-x_{k-1}). \end{equation*}
    🔗
    Next it follows that
    \begin{align*} \amp |F(x_k) - F(x_{k-1}) -f(c_k) (x_k-x_{k-1})| = \\ \amp |F(x_k) - F(c_k) + F(c_k) - F(x_{k-1}) -f(c_k) (x_k -c_k + c_k-x_{k-1})| \end{align*}
    🔗
    Thus by the triangle inequality
    \begin{align*} \amp |F(x_k) - F(x_{k-1}) -f(c_k) (x_k-x_{k-1})| \leq\\ \amp |F(x_k) - F(c_k)- f(c_k)(x_k - c_k)| + |F(c_k) - F(x_{k-1}) -f(c_k) (c_k-x_{k-1})| \end{align*}
    🔗
    Hence it follows from () and () that
    \begin{align*} \amp |F(x_k) - F(x_{k-1}) -f(c_k) (x_k-x_{k-1})| \leq \\ \amp \epsilon(x_k - c_k) + \epsilon(c_k-x_{k-1}) = \\ \amp \epsilon(x_k-x_{k-1}) \end{align*}
    🔗
    Recall that
    \begin{equation*} |F(b)-F(a) - R(f,P)| \leq \sum_{k=1}^n |F(x_k) - F(x_{k-1}) - f(c_k) (x_k-x_{k-1})| \end{equation*}
    🔗
    Hence it follows from what we’ve just shown that
    \begin{equation*} |F(b)-F(a) - R(f,P)| \leq \sum_{k=1}^n \epsilon (x_k - x_{k-1}) = \epsilon \end{equation*}
    🔗
    Hence \(f\) is generalized Riemann integrable and \(\displaystyle \int_a^b f(x)dx = F(b)-F(a)\text{.}\)
